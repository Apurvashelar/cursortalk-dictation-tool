# CursorTalk Setup Form

Standalone package of the customer setup form used to generate the customer deployment config for CursorTalk.

## Included

- React + TypeScript + Vite setup form app
- Customer setup page
- Shared CursorTalk mark component
- Form styling
- Customer config JSON schema

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Output

The form generates a JSON configuration payload intended to match:

- `schema/customer-config.schema.json`
